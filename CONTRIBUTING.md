# Contribuir a Mango AC

El repo es público. Cualquiera puede leer, clonar, jugar y proponer cambios. Solo el dueño escribe en `master`.

## Jugar y comentar

Compila como indica el [README](README.md) o usa el zip de [Releases](https://github.com/mango-computer/mango-paola-xboard/releases) si existe. Engancha el motor a una GUI UCI o xboard.

Para un fallo, una idea o una partida rara: abre un [Issue](https://github.com/mango-computer/mango-paola-xboard/issues). Incluye sistema (Linux/Windows), cómo lo compilaste o qué zip usaste, y los comandos o la posición (FEN) si aplica.

## Código

1. Haz un fork.
2. Trabaja en una rama.
3. Abre un Pull Request hacia `master`.

El núcleo de 2012 (búsqueda, evaluación, generador) se toca solo con un motivo claro. Los cambios de protocolo UCI/xboard, documentación y portabilidad son bienvenidos.
